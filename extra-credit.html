MathML has actually been around for a long time, but it was not always supported by every browser. For example, browsers like Chrome and Edge did not fully support MathML for many years. This made it hard for developers to use because their math might work on one browser but not another. More recently, browsers have added better support for MathML, so it is now much easier and more reliable to use on websites.
